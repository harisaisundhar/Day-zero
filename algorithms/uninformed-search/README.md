# Uninformed search

Breadth-first search (`bds.ipynb`), iterative deepening (`idds.ipynb`), and uniform-cost search (`UCS.ipynb` and `Solution.py`). `Uninformed Search.pdf` is the assignment.

The notebooks read `edge_list.csv`. `Solution.py` reads `aedge_list.csv`, the same edges with a `weight` column.
