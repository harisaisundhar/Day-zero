# DGA-botnet-detection

This is an implementation of the research article titled "DGA Botnet detection using Collaborative Filtering and Density Based Clustering", published in SoICT 2015. 
The paper can be found at https://dl.acm.org/doi/10.1145/2833258.2833310

`dga_domains.csv`, `top-1m.csv`, and `dns-traffic.20140614.txt` are not in the current tree. They remain in the earlier commits. Put them back beside the notebooks before a full run.
