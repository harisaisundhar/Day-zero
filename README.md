# Coursework

College projects from 2019–2022, collected into one repository and licensed under MIT. See [LICENSE](LICENSE).

The semester exercises are filed with the later projects by kind. Decks and assignment PDFs stay. Large datasets, generated build output, and the Huffman demo video are out of the current tree; those blobs remain in the earlier commits.

## Algorithms

- [clang-cast](algorithms/clang-cast) — lex and yacc course compiler
- [fuzzy-c-means](algorithms/fuzzy-c-means) — fuzzy inference and c-means
- [genetic-pso](algorithms/genetic-pso) — genetic algorithm and particle swarm
- [huff-compressor](algorithms/huff-compressor) — Huffman compressor
- [informed-search](algorithms/informed-search) — A*, best-first, and hill climbing
- [json-parser](algorithms/json-parser) — lex and yacc JSON parser
- [trie-dictionary](algorithms/trie-dictionary) — trie dictionary
- [uninformed-search](algorithms/uninformed-search) — BFS, IDDFS, and uniform-cost search
